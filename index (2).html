Learn responsibly

History needs evidence.

This starter website uses concise educational summaries. Before public launch, expand the collection with reviewed content, credible citations, and properly licensed archival media.

Sources & attribution

Use archives, museums, libraries, universities and official historical collections. Every factual article should link to sources and identify interpretations where historians differ.

About this release

This is a working starter build with local sample data and browser-based saved items. It is not yet an 800-feature production system or a fully researched archive.
